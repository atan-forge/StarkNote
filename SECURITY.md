# Security

Report security issues through GitHub's private vulnerability-reporting channel. Do not publish sensitive details in a public issue.

Include the app version, Android version, device model, and steps to reproduce.

Locked note content is encrypted on the device. Titles, timestamps, note type, and checklist details are not encrypted. The PIN controls app access but is not the encryption key.

Backup passwords cannot be recovered. A forgotten PIN requires biometric reset or deletion of locked notes. A rooted, debugged, or otherwise compromised device may expose note content.
